## 二、P0 — 必学（直接影响日常工作）

### 2.1 Chapter 1 hw3 — Transformer 全套算子手写实现

整个课程对你最重要的部分。编译器要 IR lowering、量化要逐算子处理、runtime 要调度，必须精确理解每个算子的数学定义和数值行为。

| 文件 | 为什么重要 |
|---|---|
| `chapter1/hw3/RMSnorm.py` | llama.cpp 的核心 norm，量化时需要处理其 scale 融合 |
| `chapter1/hw3/softmax.py` | 数值稳定性（max-subtract trick）、与 FlashAttention online softmax 的联系 |
| `chapter1/hw3/scaled_dot_product_attention.py` | mask 机制、`1/sqrt(d_k)` 缩放 —— 量化时这里精度敏感 |
| `chapter1/hw3/causal_multi_head_attention.py` | QKV 线性变换 + 分头/合头 + causal mask，vLLM paged attention 的数学基础 |
| `chapter1/hw3/rope.py` | 旋转位置编码 —— llama 系列的标配，编译器需要对 cos/sin cache 做特殊处理 |
| `chapter1/hw3/SwiGLU.py` | SiLU 门控 + 逐元素乘 —— 算子融合的典型场景 |
| `chapter1/hw7/transformer_no_weight_block.py` | pre-norm 残差结构，理解一个 block 内部的算子执行顺序 |

### 2.2 Chapter 1 hw6 + hw7 — 推理与完整模型组装

| 文件 | 为什么重要 |
|---|---|
| `chapter1/hw6/inference.py` | top-p sampling、temperature scaling、自回归 decode 循环 —— 理解推理的完整数据流 |
| `chapter1/hw7/final_inference.py` | 端到端推理入口 |
| `chapter1/hw7/transformermodule.py` | Embedding → N×TransformerBlock → LM Head 的完整 forward，理解整条计算图 |

## 三、P1 — 重点学习

### 3.1 Chapter 2 hw1 — Flash Attention Triton 实现

跟编译器团队对齐的核心材料：

| 文件 | 为什么重要 |
|---|---|
| `chapter2/hw1/triton_causal_forawrdflash_attention.py` | Flash Attention 前向 Triton kernel：tiling 策略、online softmax、block pointer |
| `chapter2/hw1/triton_backward_success.py` | 反向 kernel（对推理不重要，但 tiling 思路有助于和编译器同事讨论硬件映射） |
| `chapter2/hw1/flashattention_autograd_function_pytorch.py` | 自定义 autograd Function，理解如何把自定义 kernel 嵌入 PyTorch |

**核心收获**：SRAM/DRAM 数据搬运策略、分块计算 softmax 的 rescaling 技巧 —— 和自研驱动/HAL 做的事情高度相关。

### 3.2 Chapter 5 hw7 — vLLM 推理部分

`chapter5/hw7/run_grpo_train_loop.py` 直接调用了 **vLLM 的 LLM 类和 SamplingParams** 做批量推理。可以对比理解：
- vLLM 如何封装模型推理
- SamplingParams 的参数配置（temperature、top_p、max_tokens）
- 和你们定制 vLLM 版本的差异点在哪

## 六、建议学习顺序

```
第1周:  Chapter 1 hw3 全部算子 (RMSNorm → Softmax → Attention → RoPE → SwiGLU → Block)
第2周:  Chapter 1 hw6/7 推理链路 + Tokenizer
第3周:  Chapter 2 hw1 Flash Attention Triton kernel
第4周:  Chapter 5 hw7 vLLM 推理部分 + Chapter 3 Scaling Law（辅助）
```

这个顺序保证从 **算子 → 计算图 → Kernel → 推理引擎** 递进理解，和编译器、量化、推理工具链三个团队的同事都能在同一层面沟通。

## 七、学习要点总结

| 团队对接 | 你需要掌握的核心 |
|---|---|
| **编译器** | Transformer 全量算子的 IR 表达、Triton kernel 的 tiling/block pointer、算子融合模式（SwiGLU + matmul） |
| **量化** | RMSNorm scale 融合、Attention softmax 精度敏感点、RoPE cos/sin cache 处理、weight-only vs activation 量化 |
| **推理工具链 (vLLM/llama.cpp)** | PagedAttention 机制、top-p/temperature 采样、自回归 decode 循环、SamplingParams 配置 |
| **驱动/HAL/Runtime** | Flash Attention 的 SRAM/DRAM 数据搬运策略、online softmax rescaling、kernel launch 模式 |
